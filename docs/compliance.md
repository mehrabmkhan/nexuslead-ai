# Compliance Model

NexusLead AI is built as a synthetic demo.

The application does not:

- scrape real websites
- bypass platform limits
- auto-comment on posts
- collect real personal data
- auto-send outreach

Outreach drafts are stored with review statuses:

- Drafted
- Reviewed
- Approved
- Sent Manually

Any future production integration should keep human approval in the workflow before outreach is sent.
